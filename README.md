Leonida Legend — an offline GTA VI trophy guide & tracker. All 55 official PlayStation 5 trophies with their names, descriptions and grades as PlayStation publishes them, a guide to each in our own words that cites its sources, a six-stage roadmap to the platinum, a flag on the one trophy reported possibly missable, filters by kind and grade, a spoiler shield that hides story trophies until earned, and progress saved in the browser with export and import. No network at run time, no Rockstar artwork, no copied guide text.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static file server and open `app/index.html`. The guide is plain static files under `app/` (no build step); `main.ts` hands it in by copying `app/` and `screenshots/` to the output folder and writing `dossier.json`.
